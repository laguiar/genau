# Adaptation log

Every live session (lesson, drill, correction, weekly test) ends with an **adaptation pass** (rule in [AGENTS.md](../AGENTS.md) → "Adaptation rule"). This file records what was changed in forthcoming lessons and why, so changes are traceable and can be reverted. Newest at the bottom.

Adapted sections inside lesson files carry an HTML comment: `<!-- adapted YYYY-MM-DD from <session-id>: <rule> -->`.

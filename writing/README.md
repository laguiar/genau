# writing/ — your Genau texts and their corrections

```
writing/
├── submissions/   YYYY-MM-DD-<slug>.md   what you wrote, untouched
└── corrections/   YYYY-MM-DD-<slug>.md   the marked-up version + rules + clean version
```

## Correction protocol (for you or the AI tutor, see [AGENTS.md](../AGENTS.md))

1. Mark each error inline as `[wrong → right]`.
2. Below the text, one line per error: **rule** in one sentence + **topic id** to re-read.
3. A clean corrected version.
4. One thing that was good (a structure used correctly).
5. For telc-format letters: grade **Inhalt / Aufbau / Richtigkeit / Register** 0–5 each, and word count.
6. Add every error to `review/error-log.md`.

## What to write, by level

- **A1:** 5 sentences per topic; a form; a 3-line message to a friend.
- **A2:** short e-mails (40–80 words) with 3 given points; from A2-22, semi-formal.
- **B1:** the telc letter (4 points, ~150 words, 30 min), twice a week; plus a 5-sentence opinion paragraph.

Write by hand first if you can (slower, more noticing), then type it here.

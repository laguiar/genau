# A1 — the sentence skeleton and the first two cases

**Why redo A1 if you are A2?** Because B1 writing fails on A1 errors: wrong gender, verb not in second position, `nicht` vs `kein`, missing `-en` on the accusative. Each topic starts with a **diagnostic**; score ≥ 90 % and you mark it `✔` in 3 minutes and move on. Expect to genuinely study maybe a third of these.

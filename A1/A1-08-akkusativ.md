# A1-08 — Akkusativ ▲

**Level:** A1 · **Time:** 2 sessions · **Prerequisites:** A1-05, A1-07 · **Nicos Weg:** [Wem gehört das?](https://learngerman.dw.com/de/wem-gehört-das/l-40393806), [Lebensmittel](https://learngerman.dw.com/de/lebensmittel/l-40465283)
**Can-do:** I can mark the direct object with the right article, `kein` and pronoun forms, and recognise the few situations that always take ▲.

## 1. The rule in one picture

```
 ▲ Akkusativ = the direct object  →  question: WEN? (people)  WAS? (things)
                                     Ich sehe WEN? → den Mann.   Ich kaufe WAS? → das Brot.

             m         n        f        pl
 der-word    DEN       das      die      die        ← only the masculine changes!
 ein-word    EINEN     ein      eine     —
 kein        KEINEN    kein     keine    keine
 pronouns    ich→MICH  du→DICH  er→IHN  es→es  sie→sie  wir→UNS  ihr→EUCH  sie/Sie→sie/Sie
 question    wer→WEN   was→was

 ALWAYS ▲:   after  für · ohne · gegen · um · durch          (für dich, ohne mich, um den Tisch)
             time spans and points without preposition       jeden Tag · nächste Woche · den ganzen Tag
             es gibt …                                        Es gibt einen Park.
 NEVER ▲:    after sein / werden / bleiben  → ●              Das ist ein Tisch. Er ist mein Freund.
```

## 2. The rule in words

**What ▲ marks.** The thing or person the action is done to: *Ich kaufe **den Apfel**. Sie kennt **den Lehrer**. Wir besuchen **eine Freundin**.* Most verbs that take an object take ▲: *haben, brauchen, kaufen, essen, trinken, lesen, sehen, suchen, finden, kennen, lieben, besuchen, nehmen, möchten, verstehen, hören, machen, schreiben, lernen, fragen, treffen, tragen, bekommen, öffnen*.

**Only the masculine changes.** *der → den, ein → einen, kein → keinen, mein → meinen*. Neuter, feminine and plural look exactly like ●. So the whole topic is: **is the object masculine? then add `-en`.**

**Pronouns.** *ich → mich, du → dich, er → ihn, wir → uns, ihr → euch*. *es, sie, Sie* do not change. *Ich liebe **dich**. Kennst du **ihn**? Sie sieht **uns**.*

**Question words.** *Wen?* for people, *Was?* for things: *Wen besuchst du? — Meinen Bruder. Was kaufst du? — Einen Apfel.*

**Fixed ▲ contexts.** (a) The five prepositions *für, ohne, gegen, um, durch* (A2-03 has the full list): *ein Geschenk **für meinen** Vater, **ohne dich**.* (b) Time expressions without a preposition: *jeden Tag, jeden Morgen, nächsten Monat, letzte Woche, den ganzen Tag, einen Moment*. (c) *es gibt* (there is/are): *Es gibt **einen** Supermarkt.* (d) Greetings and wishes: *Guten Morgen! Guten Tag! Schönen Abend! Gute Nacht!* — these are ▲ because *Ich wünsche dir …* is implied.

**Not ▲ after `sein`.** *Das ist **ein** Tisch* / *Er ist **mein** Bruder* / *Das wird **ein** Problem* — both sides of *sein/werden/bleiben* are ●.

> 🇧🇷 **Portuguese contrast** — PT marks the object only on pronouns (*Eu o vejo / Vejo-o*; *me, te, nos*). Map: *me* → *mich*, *te* → *dich*, *o* → *ihn*, *a* → *sie*, *nos* → *uns*, *vos/vocês* → *euch*. The new part: **articles** change too, and only for masculine. PT object pronouns go before the verb (*Eu te amo*); German puts them **after** the conjugated verb: *Ich liebe dich.*
> 🇪🇸 **Spanish contrast** — **Watch the Spanish "personal *a*" trap!** In Spanish, human direct objects take the preposition *a* (*Veo **a** mi hermano / Busco **al** médico*). In German, direct objects take the **`▲` Akkusativ with NO preposition** (*Ich sehe **meinen** Bruder / Ich suche **den** Arzt*). Only masculine singular changes its article in `▲` (`der → den, ein → einen, kein → keinen`).
> 🇫🇷 **French contrast** — Think of `● Nominativ` as the French subject (*il / qui*) and `▲ Akkusativ` as the French COD (*le / que*). Only the masculine singular article changes in `▲` (*der → **den**, ein → **einen**, kein → **keinen***). French has no partitive article in German: *Je bois **du** café / je cherche **des** amis* → *Ich trinke **—** Kaffee / ich suche **—** Freunde* (zero article!).
> 🇬🇧 **English contrast** — *him* = *ihn* (m), but *it* = *es* (n) or *ihn* (m) or *sie* (f) depending on the noun's gender: *Der Tisch? Ich kaufe **ihn**. Das Buch? Ich kaufe **es**. Die Lampe? Ich kaufe **sie**.*

## 3. Watch out

- *Ich habe einen Bruder* (▲) but *Das ist ein Bruder von mir* (● after *sein*).
- *Ich habe **keinen** Hunger / **keinen** Durst / **keine** Zeit / **kein** Geld* — *Hunger* and *Durst* are masculine.
- *Guten Tag* but *Gute Nacht* (*die Nacht*, feminine, no change).
- Pronouns referring to things keep the noun's gender: *Wo ist der Schlüssel? — Ich habe **ihn**.*
- *wen* (whom) vs *wer* (who): *Wen siehst du?* (object) / *Wer sieht dich?* (subject).

# Connectors to B1 — the three-column model

Every connector belongs to exactly one column. The column tells you where the verb goes. See [word-order.md §4](word-order.md).

| Meaning | **Konjunktor** (pos. 0 · verb stays 2nd) | **Subjunktor** (verb to the END) | **Verbindungsadverb** (pos. 1 · verb 2nd, subject after) |
|---------|--|--|--|
| reason | **denn** | **weil**, da | **deshalb, deswegen, darum, daher**, aus diesem Grund |
| contrast / concession | **aber**, doch | **obwohl**, obgleich | **trotzdem**, dennoch, allerdings, jedoch |
| addition | **und**, sowie | — | **außerdem**, auch, dazu, zudem, ebenfalls |
| alternative | **oder** | — | sonst, andernfalls |
| correction | **sondern** (after negation) | — | — |
| time: sequence | — | **nachdem** (+ Plusquamperfekt/Perfekt), **bevor**, **sobald**, **bis**, **seit(dem)** | **dann, danach, zuerst, später, vorher, schließlich, inzwischen** |
| time: simultaneous | — | **während**, **als** (one-time past), **wenn** (repeated / present / future), **solange** | gleichzeitig, dabei |
| condition | — | **wenn**, **falls**, sofern | sonst (= otherwise), dann |
| purpose | — | **damit** (different subjects), **um … zu** (same subject) | dafür |
| consequence | — | **so dass** / **so … dass** | **also**, deshalb, folglich |
| manner / means | — | **indem** | so, dadurch |
| content | — | **dass**, **ob**, W-words (*wann, wo, wie, warum, wer…*) | — |
| comparison | — | **als** (unequal), **(so) … wie** (equal), **je … desto** | — |

## Two-part connectors (B1-10)

| Pair | Meaning | Word order |
|------|---------|-----------|
| **entweder … oder** | either … or | `entweder` pos. 1 (verb 2nd) or pos. 0; `oder` pos. 0 |
| **nicht nur … sondern auch** | not only … but also | both pos. 0 / inside the clause |
| **sowohl … als auch** | both … and | joins phrases, no verb move |
| **weder … noch** | neither … nor | `weder` pos. 1 → verb 2nd; `noch` pos. 1 → verb 2nd: *Ich habe **weder** Zeit **noch** Lust* / ***Weder** habe ich Zeit, **noch** habe ich Lust.* |
| **zwar … aber** | admittedly … but | `zwar` pos. 1 → inversion; `aber` pos. 0 |
| **je … desto/umso** | the … the | `je` + comparative + clause with verb at END, `desto` + comparative + verb 2nd: *Je mehr ich lese, desto besser verstehe ich.* |

## Same meaning, three shapes — drill set

| Reason | Contrast | Time |
|--------|----------|------|
| Ich bleibe zu Hause, **denn** ich **bin** krank. | Ich gehe hin, **aber** ich **habe** keine Lust. | Ich esse, **und** dann **gehe** ich. |
| Ich bleibe zu Hause, **weil** ich krank **bin**. | Ich gehe hin, **obwohl** ich keine Lust **habe**. | **Nachdem** ich gegessen **habe**, gehe ich. |
| Ich bin krank. **Deshalb bleibe** ich zu Hause. | Ich habe keine Lust. **Trotzdem gehe** ich hin. | Ich esse. **Danach gehe** ich. |

## Traps the exam loves

- `denn` vs `weil`: same meaning, different verb position. Only `weil` can start the sentence.
- `wenn` vs `als`: **als** = a single event in the past (*Als ich 10 war…*); **wenn** = repeated, or present/future (*Wenn ich Zeit habe…*, *Immer wenn…*).
- `wann` only in questions (direct or indirect): *Ich weiß nicht, **wann** er kommt.* Never as a conditional.
- `ob` = whether (yes/no inside), `dass` = that (fact inside): *Ich weiß nicht, **ob** er kommt* / *Ich weiß, **dass** er kommt.*
- `damit` vs `um … zu`: same subject → `um … zu` preferred; different subjects → `damit`.
- `trotzdem` needs inversion: ***Trotzdem gehe ich*** — never *Trotzdem ich gehe*.
- `sondern` only after a negation: *nicht heute, **sondern** morgen*.
- `aber` can also sit inside the clause as an adverb: *Ich habe **aber** keine Zeit.*

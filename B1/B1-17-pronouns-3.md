## 1. The rule in one picture

```
 1. DERSELBE (the exact same single object) vs DER GLEICHE (an identical copy/type)
    Part 1 (der/das/die…) declines as article  +  Part 2 (-selb- / gleich-) declines as Rule-A ADJECTIVE!
            m               n                f               pl
    ●       derselbe        dasselbe         dieselbe        dieselben        (written as ONE word!)
    ▲       denselben       dasselbe         dieselbe        dieselben
    ■       demselben       demselben        derselben       denselben        (im selben = in demselben)
    Compare:  der gleiche   das gleiche      die gleiche     die gleichen     (written as TWO words!)

 2. RECIPROCAL "EINANDER" ("each other / one another")
    sich (= uns / euch / sich)  ↔  einander (never changes form!)
    Preposition + einander fuses into ONE word:  miteinander · füreinander · voneinander · durcheinander · aufeinander
    Wir sprechen oft MITEINANDER.   Sie helfen EINANDER (= Sie helfen sich gegenseitig).

 3. INDEFINITES: IRGEND- ("some-/any-") and MANCHER / EINIGE / MEHRERE
    irgendwer / irgendjemand (someone) · irgendetwas / irgendwas (something) · irgendwo / irgendwann / irgendwie
    irgendein (+ noun, like ein) · irgendwelche (+ pl./uncountable noun, like dieser)
    mancher / manche / manches ("some, many a" — declines like dieser; plural adj. after manche takes -en!)

 4. IDIOMATIC "ES" CONSTRUCTIONS (Schreiben & Lesen!)
    Es gibt + ▲ · Es geht um + ▲ · Es handelt sich um + ▲ · Es kommt darauf an, ob … · Es tut mir leid, dass …
    Correlative "es" in the Mittelfeld:   Ich finde ES wichtig / schade / toll, dass … (or … zu + Infinitiv)
```

## 2. The rule in words

**1. `derselbe` vs `der gleiche`.**
- **derselbe / dasselbe / dieselbe** (written as **one** word) means the **very same single item** shared by two people or occasions: *Anna und ihr Mann fahren **dasselbe** Auto* (they only own one car together). *Wir wohnen **im selben** (= in demselben) Haus.*
- **der / das / die gleiche** (written as **two** words, or after *ein*: *ein gleicher*) means **the same model/type, alike**: *Anna und ich fahren **das gleiche** Auto* (two separate cars of the same brand).
- Both decline identically: definite article first (`der/den/dem/des…`) + weak Rule-A adjective ending (`-e` in the 5 basic cells, `-en` everywhere else: *mit **derselben** Kollegin, am **gleichen** Tag*).

**2. `einander` and `sich (gegenseitig)` ("each other").**
In plural, reflexive pronouns (*uns, euch, sich*) can already mean "each other": *Wir lieben **uns**. Wir sehen **uns** morgen.* To avoid ambiguity or **after a preposition**, German uses **einander** (invariable!), glued directly onto the preposition as **one word**:
- *Wir kennen uns schon lange und vertrauen **einander**.*
- ***miteinander*** (with each other), ***füreinander*** (for each other), ***voneinander*** (from each other), ***aufeinander*** (on/for each other), ***nebeneinander*** (next to each other), ***nacheinander*** (one after another), ***durcheinander*** (mixed up / confused).

**3. `irgend-` and `manche / einige / mehrere`.**
- Prefixing **irgend-** to a W-word or indefinite pronoun adds the nuance *"some … or other / any at all"*: *irgendwann* (at some point), *irgendwo* (somewhere), *irgendwie* (somehow), *irgendjemand* (someone/anyone), *irgendetwas / irgendwas* (something/anything), *irgendein Buch* (singular), *irgendwelche Fragen* (plural).
- **mancher (-e, -es)** ("many a / some") declines like *dieser*; in plural (*manche Leute*), a following adjective usually takes **-en** (*manche alt**en** Häuser*), whereas after **einige / mehrere / viele / wenige** (a few / several / many / few) the adjective takes strong Rule-C endings (*einige gut**e** Freunde*, A2-18).

**4. `es`-constructions for B1 Reading and Writing.**
- **Obligatory subject `es`** (never drop it, even on inversion!): *In dem Artikel **geht es um** die Umwelt. Bei dem Angebot **handelt es sich um** einen Intensivkurs. **Es kommt darauf an**, wie viel Zeit Sie haben. **Es gibt** viele Möglichkeiten. **Es fehlt** mir **an** der nötigen Erfahrung.*
- **Placeholder `es` inside the main clause** before *dass* or *zu + Infinitiv* after verbs like *finden, halten für, machen*: *Ich finde **es** sehr schade, dass der Kurs ausfällt. Das macht **es** einfacher, einen Termin zu finden.*

> 🇧🇷 **Portuguese contrast** — PT uses *o mesmo carro* for both one shared car and two identical cars; German separates **dasselbe Auto** (1 car) and **das gleiche Auto** (2 identical cars) · PT *um com o outro / uns aos outros* → one word in German: **miteinander / einander** · PT drops the dummy subject (*Trata-se de um erro / Acho importante que…*). German **requires `es`**: *Es handelt sich um einen Fehler / Ich finde **es** wichtig, dass …*.
> 🇪🇸 **Spanish contrast** — Spanish uses *el mismo / la misma* for both one shared item and two identical items. German separates **derselbe / dasselbe / dieselbe** (one single shared object: *Vivimos en el mismo edificio → im **selben** Haus*) from **der / das / die gleiche** (an identical copy/model: *Tienes la misma chaqueta que yo → **die gleiche** Jacke*). Spanish *el uno con el otro / entre sí* fuses into **miteinander** (*füreinander, voneinander*). And Spanish *Se trata de…* requires the subject **`es`** in German: **Es handelt sich um + `▲`** / **Es geht um + `▲`** (*In dem Text **geht es um**…*).
> 🇫🇷 **French contrast** — French uses *le même / la même* for both one shared object and two identical objects. German distinguishes **derselbe / dasselbe / dieselbe** (one single shared item: *Nous habitons dans le même immeuble → im **selben** Haus*) from **der / das / die gleiche** (an identical model: *Tu as la même veste que moi → **die gleiche** Jacke*). French *l'un avec l'autre / ensemble* fuses into **miteinander** (*füreinander, voneinander*). And French *Il s'agit de…* = **Es handelt sich um + ▲** / **Es geht um + ▲** (never drop `es`!).
> 🇬🇧 **English contrast** — English also uses *the same* for both *derselbe* and *der gleiche*. And where English says *I find **it** hard to believe*, German uses the same placeholder *es*: *Ich finde **es** schwer zu glauben*.

## 3. Watch out

- Writing *der selbe* as two words or forgetting to decline the first half: ~~in der selbe Straße~~ → *in **derselben** Straße*.
- Dropping `es` when another element is in position 1 with *es gibt / es geht um / es handelt sich um*: ~~In diesem Buch geht um Liebe~~ → *In diesem Buch **geht es** um Liebe.*
- Using *irgendein* in plural: plural is **irgendwelche** (*Haben Sie noch **irgendwelche** Fragen?*).

## 4. Exercises (no peeking)

**4.1 `derselbe` (1 shared item) vs `der gleiche` (2 identical items) — decline in the right case!** —
1. Mein Mann und ich wohnen seit zwanzig Jahren in (same — 1 flat!) ___ Wohnung.
2. Kaufst du dir schon wieder (same — identical model) ___ Schuhe wie letztes Jahr?
3. Wir sind beide am (same — 1 calendar date) ___ Tag geboren: am 12. Mai 1995.
4. Meine Schwester hat genau (same — alike) ___ Augen wie unsere Mutter.
5. Wir fliegen mit (same — 1 plane) ___ Flugzeug nach Lissabon.
6. Er macht immer wieder (same — type of) ___ Fehler.

**4.2 Preposition + `einander`** — Fill in `einander, miteinander, füreinander, voneinander, aufeinander, nebeneinander`:
1. In einer guten Ehe sollte man immer ___ da sein (for each other).
2. Nach dem Streit haben die beiden Brüder wochenlang nicht ___ gesprochen (with each other).
3. Unsere beiden Häuser stehen direkt ___ (next to each other).
4. Obwohl sie in verschiedenen Städten leben, hören sie regelmäßig ___ (from each other).
5. Wir müssen ___ Rücksicht nehmen (on each other: *Rücksicht nehmen auf*).
6. Die Teilnehmer stellten sich am Anfang des Kurses ___ vor (to each other, ■).

**4.3 Indefinites (`irgend-`, `manche`, `einige`, `all-`)** — Fill in:
1. Ich finde meinen Schlüssel nicht; er muss doch ___ (somewhere) in der Wohnung sein!
2. Hat ___ (anyone) von euch meine Brille gesehen?
3. Wenn Sie noch ___ (any, pl.) Fragen haben, rufen Sie mich gern an.
4. ___ (Some) Menschen lernen am besten morgens, andere lieber abends.
5. Wir haben uns schon ___ (several) Wohnungen angesehen, aber noch nichts gefunden.

**4.4 Idiomatic `es`-sentences** — Build or complete the sentence with `es`:
1. In Ihrer Anzeige / gehen / um / eine Stelle als Verkäufer →
2. Bei diesem Formular / sich handeln / um / eine Anmeldebestätigung →
3. Ich / finden / sehr wichtig, / dass / die Kinder früh schwimmen lernen →
4. Mir / leidtun, / dass / ich gestern nicht anrufen konnte →
5. Darauf ankommen, / ob / das Wetter am Samstag schön bleibt →

**4.5 Sprachbausteine-style**

1. Mein Kollege und ich fahren jeden Morgen mit ___ Zug zur Arbeit. (a) der gleichen (b) demselben (c) derselbe
2. Bei unserer Arbeit ist es wichtig, dass wir offen ___ kommunizieren. (a) füreinander (b) voneinander (c) miteinander
3. Ich finde ___ sehr freundlich von Ihnen, dass Sie mich vom Bahnhof abholen. (a) das (b) es (c) —
4. Bei dem Dokument, das ich Ihnen schicke, handelt ___ sich um eine Kopie des Vertrags. (a) er (b) das (c) es
5. Falls Sie noch ___ Wünsche haben, teilen Sie uns diese bitte rechtzeitig mit. (a) irgendwelche (b) irgendeine (c) irgendwas

## 1. The rule in one picture

```
 1. NOUN BUILDERS (Suffix fixes the gender 100 %!)
    Verb stem + -UNG   → ALWAYS DIE (pl. -en)       wohn-en → die Wohnung · bestell-en → die Bestellung · lös-en → die Lösung
    Adjective + -HEIT  → ALWAYS DIE (pl. -en)       gesund → die Gesundheit · frei → die Freiheit · sicher → die Sicherheit
    Adjective + -KEIT  → ALWAYS DIE (pl. -en)       möglich → die Möglichkeit · pünktlich → die Pünktlichkeit
                         (after -ig, -lich, -sam, -bar, -er)
    Verb stem + -ER    → ALWAYS DER (agent/tool)    fahr-en → der Fahrer · druck-en → der Drucker (+ -IN → die Fahrerin)
    Infinitive as noun → ALWAYS DAS (no plural)     lesen → das Lesen · beim Kochen · zum Schwimmen

 2. ADJECTIVE BUILDERS
    Noun + -IG / -LICH / -ISCH     der Tag → täglich · die Sonne → sonnig · Europa → europäisch
    Verb stem + -BAR (= -able)     ess-en → essbar · lös-en → lösbar · erreich-en → erreichbar
    Noun + -LOS (= without)        die Arbeit → arbeitslos · die Kosten → kostenlos · das Problem → problemlos
    UN- + Adjective (= opposite)   freundlich → unfreundlich · pünktlich → unpünktlich · bekannt → unbekannt

 3. COMPOUND NOUNS (Read from RIGHT to LEFT! Last word = base meaning + gender + plural)
    die Kranken + das Haus                         = DAS Krankenhaus (type of house)
    das Krankenhaus + der Aufenthalt (der, -e)     = DER Krankenhausaufenthalt (type of stay)
    Linking letters (Fugen-s / -n):   die Arbeit + s + der Platz = der Arbeitsplatz · die Woche + n + das Ende = das Wochenende

 4. VERB PREFIXES (meaning clues for Lesen)
    BE-  makes a verb transitive (takes ▲!)        antworten (auf) → die Frage BEantworten · sprechen (über) → etwas BEsprechen
    VER- change / away / wrong / noun-adj→verb     besser → VERbessern · derSchlaf → VERschlafen (oversleep) · sich VERfahren (get lost)
    ENT- away / remove / start                     ENTfernen (remove) · ENTdecken (discover) · ENTstehen (arise)
    ZER- into pieces                               ZERstören (destroy) · ZERbrechen (shatter)
```

## 2. The rule in words

**Why word formation is your secret weapon for telc B1 Lesen.** German builds new vocabulary by snapping known roots, prefixes and suffixes together. Instead of panicking when you see a 22-letter word in a reading text (*Krankenversicherungsbeitrag*), slice it from the right: *der Beitrag* (contribution/fee) ← *die Versicherung* (insurance) ← *die Kranken* (sick people) = health insurance fee.

**1. Turning verbs and adjectives into nouns (and getting gender for free).**
- **Verb stem + `-ung` → `die` (pl. `-ungen`):** Almost any action verb with prefixes *an-, be-, er-, ver-, ein-, aus-* forms its action/result noun in `-ung`: *einladen → die Einladung, prüfen → die Prüfung, beschreiben → die Beschreibung, verspäten → die Verspätung, erfahrung → die Erfahrung, Heizung, Meinung, Übung, Rechnung, Reservierung*.
- **Adjective + `-heit` or `-keit` → `die` (pl. `-en`):** Turns a quality into an abstract noun. Short adjectives take **-heit** (*krank → die Krankheit, wahr → die Wahrheit, zufrieden → die Zufriedenheit, schön → die Schönheit*); adjectives ending in **`-ig, -lich, -sam, -bar`** take **-keit** (*freundlich → die Freundlichkeit, wichtig → die Wichtigkeit, einsam → die Einsamkeit, dankbar → die Dankbarkeit, Aufmerksamkeit, Tätigkeit, Schwierigkeit*).
- **Infinitive as a noun → `das`:** Any verb infinitive can become a neuter noun simply by capitalising it: *das Essen, das Leben, das Schwimmen, das Einkaufen*. Very common after **beim** (*beim Lesen* = while reading) and **zum** (*etwas zum Trinken* = something to drink).

**2. Adjective suffixes and prefixes.**
- **`-bar`** added to a verb stem means **"can be done"** (*-able/-ible*): *bezahlbar* (affordable), *machbar* (feasible), *lesbar* (legible), *erreichbar* (reachable), *lieferbar* (available for delivery).
- **`-los`** added to a noun (often with linking `-s-` or `-n-`) means **"without"** (*-less*): *kostenlos* (free), *arbeitslos* (unemployed), *bargeldlos* (cashless), *sinnlos* (pointless).
- **`un-`** negates adjectives and nouns: *unmöglich, ungesund, unabhängig, der Unfall, das Unglück*. (**`miss-`** negates verbs/nouns: *missverstehen → das Missverständnis*).

**3. Inseparable verb prefixes in reading and writing.**
- **`be-`** turns an intransitive verb + preposition into a direct **▲ transitive verb** (great for formal letters!):
  - *auf eine Frage antworten* → *eine Frage **be**antworten*
  - *über ein Problem sprechen* → *ein Problem **be**sprechen*
  - *in einem Haus wohnen* → *ein Haus **be**wohnen*
  - *für die Ware zahlen* → *die Ware **be**zahlen*
- **`ver-`** has three core patterns: (a) turning an adjective into a "make more X" verb (*länger → **ver**längern* = extend/renew, *besser → **ver**bessern* = improve, *größer → **ver**größern*, *einfach → **ver**einfachen*), (b) doing something **wrong / too much** (*sich **ver**schreiben* = make a typo, *sich **ver**laufen / **ver**fahren* = get lost, ***ver**schlafen* = oversleep, ***ver**passen* = miss), (c) away/passing (*die Zeit **ver**geht, **ver**reisen, **ver**kaufen*).

> 🇧🇷 **Portuguese contrast** — `-ung` ≈ PT `-ção` (*die Information, die Reservierung = a reserva, die Erklärung = a explicação*) · `-heit / -keit` ≈ PT `-dade / -eza` (*die Möglichkeit = a possibilidade, die Freiheit = a liberdade*) · `-bar` ≈ PT `-vel` (*essbar = comestível, erreichbar = alcançável*) · `-los` ≈ PT *sem + substantivo* (*kostenlos = sem custo / gratuito*) · PT *ao ler / durante a leitura* → German **beim Lesen** (*bei dem* + capitalised infinitive!).
> 🇪🇸 **Spanish contrast** — Many suffixes map directly from Spanish: Spanish `-ción / -miento` ≈ German **`-ung`** (always `die`: *die Reservierung, die Erklärung*); Spanish `-dad / -eza` ≈ German **`-heit / -keit`** (always `die`: *die Möglichkeit = la posibilidad, die Sicherheit = la seguridad*); Spanish `-ble` = German **`-bar`** (*lösbar, erreichbar*); Spanish *sin + noun* = **`-los`** (*kostenlos = gratuito / sin costo*). And Spanish *al leer / leyendo* = **`beim Lesen`** (`bei dem` + capitalised infinitive!).
> 🇫🇷 **French contrast** — Many abstract nouns correspond cleanly: French `-tion / -ment` ≈ German **`-ung`** (always `die`: *die Reservierung, die Erklärung*); French `-té / -esse` ≈ German **`-heit / -keit`** (always `die`: *die Möglichkeit = la possibilité, die Freiheit = la liberté*); French `-able / -ible` = German **`-bar`** (*lösbar, erreichbar*); French *sans + noun* = **`-los`** (*kostenlos = gratuit / sans frais*). French *en lisant / pendant la lecture* = **`beim Lesen`** (`bei dem` + capitalised infinitive!).
> 🇬🇧 **English contrast** — English writes compounds as separate words (*language course registration form*). German glues them into one word (*das Sprachkursanmeldeformular*). Always find the **last** word first to know the gender and what the thing actually is.

## 3. Watch out

- Forgetting to capitalise nominalised infinitives after *beim / zum / das*: ~~beim kochen~~ → *beim **K**ochen*; ~~viel Spaß beim deutschlernen~~ → *beim **D**eutschlernen*.
- Keeping the preposition when switching to a `be-` verb: ~~Ich beantworte auf Ihre Frage~~ → *Ich **beantworte Ihre Frage*** (▲) OR *Ich **antworte auf Ihre Frage***.
- Guessing the gender of a compound from the first word instead of the **last** word: *die Kinder* + *das Zimmer* = **das** Kinderzimmer.

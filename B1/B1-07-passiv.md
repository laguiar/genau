## 1. The rule in one picture

```
 VORGANGSPASSIV (Process / Action)  =  WERDEN  +  PARTIZIP II
   Tense              V2 (conjugated)    Mittelfeld               V-END
   Präsens            Das Paket WIRD     heute                    GELIEFERT.
   Präteritum         Das Paket WURDE    gestern                  GELIEFERT.       ← standard past in writing!
   Perfekt            Das Paket IST      schon                    GELIEFERT WORDEN. (worden, NEVER geworden!)
   Modal + Präsens    Das Paket MUSS     bis Freitag              GELIEFERT WERDEN. (Partizip II + werden!)
   Nebensatz          …, weil das Paket  morgen                   GELIEFERT WIRD / GELIEFERT WERDEN MUSS.

 ACTIVE  →  PASSIVE TRANSFORMATION
   Active:   [ Der Mechaniker ● ]   repariert   [ das Auto ▲ ].
   Passive:  [ Das Auto ● ]         wird        (vom Mechaniker)   repariert.
             ↑ ▲ object becomes ● subject!      ↑ VON ■ = person/agent · DURCH ▲ = cause/means

 ALTERNATIVES & STATE PASSIVE
   Active with "man":   Man baut hier eine Schule.  ↔  Hier wird eine Schule gebaut.
   Zustandspassiv:      sein + Partizip II = result/state:  Das Fenster IST geöffnet (= open).
```

## 2. The rule in words

**Why Passiv matters at B1.** The focus is on **what happens**, not who does it — so signs, instructions, letters from offices, contracts, and news articles (Leseverstehen + Sprachbausteine) are full of it.

**The core formula: `werden + Partizip II`.**
- **Präsens:** *ich werde, du wirst, er/sie/es **wird**, wir werden, ihr werdet, sie/Sie **werden** + Partizip II*: *Die Rechnung **wird** morgen **bezahlt**.*
- **Präteritum** (preferred over Perfekt for passive whenever possible!): *ich/er **wurde**, wir **wurden** + Partizip II*: *Die E-Mail **wurde** gestern **geschickt**.*
- **Perfekt:** *ist / sind + Partizip II + **worden*** (drops the *ge-* of *geworden*!): *Das Problem **ist** schon **gelöst worden**.*
- **With modal verbs:** modal in position 2 + **Partizip II + werden** at the end: *Das Formular **muss** bis Montag **abgegeben werden**. Hier **darf** nicht **geparkt werden**.* In a Nebensatz, the conjugated modal goes to the very end: *…, weil das Formular **abgegeben werden muss**.*

**How to turn Active into Passive.**
1. The **▲ Akkusativ object** of the active sentence becomes the **● Nominativ subject** of the passive sentence (*Man prüft **den Vertrag** ▲* → ***Der Vertrag** ● wird geprüft*).
2. A **■ Dativ object** stays ■ Dativ! (*Man hilft **dem Kunden** ■* → ***Dem Kunden** ■ wird geholfen* — singular verb *wird* because there is no ● subject!).
3. If you want to name the doer: use **von + ■** for a person, institution or force (*von meinem Chef, von der Polizei, vom Sturm*) and **durch + ▲** for an instrument, cause or process (*durch einen Fehler, durch ein Feuer*). If the active subject is **man**, drop it completely in the passive.

**Process (`werden`) vs State (`sein`).**
- *Um 18 Uhr **wird** der Laden **geschlossen*** = someone is locking the door at 6 pm (action).
- *Ab 18 Uhr **ist** der Laden **geschlossen*** = the shop is closed from 6 pm on (state = Zustandspassiv, *sein + Partizip II*).

> 🇧🇷 **Portuguese contrast** — Portuguese forms the passive with **ser / estar + particípio** (*A carta **é** escrita / **foi** escrita*). Because *ser* = *sein*, Brazilian learners automatically write ~~Der Brief ist geschrieben~~ when they mean an action! Lock in the contrast: - PT **ser** + particípio (action) → German **werden** + Partizip II (*Der Brief **wird** / **wurde** geschrieben*). - PT **estar** + particípio (resulting state) → German **sein** + Partizip II (*Der Brief **ist** fertig geschrieben*). - PT *se*-passive (*Aluga-se apartamento / Fala-se alemão*) → German **man** or **wird + Partizip II**.
> 🇪🇸 **Spanish contrast** — **Your best Spanish anchor for the Passive:** Spanish clearly separates **ser + participio** (process/action: *La puerta **es / fue** cerrada a las 8*) from **estar + participio** (resulting state: *La puerta **está / estaba** cerrada*). Map them 1:1 to German: - Spanish **ser + participio** (action) = German **`werden` + Partizip II** (*Die Tür **wird / wurde** um 8 Uhr geschlossen; **ist** geschlossen **worden***). - Spanish **estar + participio** (state) = German **`sein` + Partizip II** (*Die Tür **ist / war** geschlossen*). - Spanish *pasiva refleja* with ***se*** (*Aquí no **se** fuma / **Se** reparan coches*) = German **`man`** or **`wird + Partizip II`** (*Hier raucht **man** nicht / Hier **wird** nicht geraucht*).
> 🇫🇷 **French contrast** — This is a major French → German trap: French forms the passive with ***être* + participe passé** (*La voiture **est** réparée / **a été** réparée*). If you translate *est / était / a été* with `ist / war`, you get the **state passive** (already finished)! For an **action** (process passive), always use **`werden`**: *Das Auto **wird** repariert (est réparée) / **wurde** repariert (a été réparée) / **ist** repariert **worden***. French ***on*** (*On répare la voiture*) maps directly to German **`man`** (*Man repariert das Auto*).
> 🇬🇧 **English contrast** — Same trap: English uses *to be* (*is built, was built*) for both action and state. In German, action = **wird / wurde gebaut**; state = **ist gebaut**.

## 3. Watch out

- Writing *ist/war* instead of *wird/wurde* for an action: ~~Das Auto war gestern repariert~~ → *Das Auto **wurde** gestern repariert.*
- Writing *geworden* instead of *worden* in Perfekt Passiv: ~~Er ist operiert geworden~~ → *Er ist operiert **worden**.* (*ist … geworden* means "has become": *Er ist Arzt geworden*).
- Modal + Passive uses **werden** (infinitive), not *worden*: *Das muss gemacht **werden**.*
- Keeping ▲ on the new subject: ~~Den Brief wird geschickt~~ → ***Der Brief** ● wird geschickt.*

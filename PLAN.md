# PLAN — Genau syllabus A1 → B1 for the telc Deutsch B1 exam

## Goal and constraints

- **Goal:** pass telc Deutsch B1 (written part: Lesen + Sprachbausteine 90 min, Hören 30 min, Schreiben 30 min; oral part separate). Focus here: Lesen, Sprachbausteine, Schreiben.
- **Learner profile assumed:** adult, self-study, ~30 min/day, already exposed to A1/A2 once, reads English. The plan still starts at A1 because gaps at A1 (gender, cases, verb position) are what make B1 writing fail.
- **Coverage standard:** every structure listed for A1, A2 and B1 in *Profile deutsch* "Grammatik: Übersicht A1–B2" is covered, plus a few B2-listed items that telc B1 Sprachbausteine regularly test (`indem`, `sobald`, `dennoch`, `zwar … aber`). B2 structures are otherwise excluded on purpose.

## Sequencing principles

1. **Form before function spread.** A form is introduced once at the lowest level where Profile deutsch lists it, then *re-entered* at the next level with wider use (Dativ I → Dativ II; Perfekt I → II; Konjunktiv II I → II; relative clauses I → II).
2. **Sentence skeleton early.** Verb position (A1-04, A1-10, A1-19) comes before most morphology, because word order errors are the most visible in writing and the most frequent Sprachbausteine trap.
3. **Cases as one system.** The same `● ▲ ■ ◆` code and the same master table ([shared/cases.md](shared/cases.md)) are used from A1-05 to B1-02, so every new ending is a new row in a known table, not a new topic.
4. **Every level ends with an exam-format consolidation** (A1-21, A2-22, B1-22) so the exam format is never new.
5. **Interleaving is built in:** the review queue mixes topics; weekly live tests mix levels.

## Pacing

| Phase | Topics | Days at 30 min/day | Notes |
|-------|--------|--------------------|-------|
| A1 review | 21 | ~25 | Diagnostics let you skip known topics in 1 day each |
| A2 | 22 | ~45 | 2 days per topic |
| B1 | 22 | ~55 | 2–3 days per topic; writing tasks longer |
| Exam phase | mocks | ~20 | 1 full mock per week, error-driven revision |
| **Total** | 65 | **~5 months** | Faster if A1 is mostly `✔ known` |

Any order and any pace is fine. The plan is a map, not a calendar.

## Topic template

Each topic file has the same sections (template: [shared/lesson-template.md](shared/lesson-template.md)):

`Diagnostic` → `What you can do after this` (CEFR can-do) → `Explanation` (dual-coded) → `🇧🇷 / 🇪🇸 / 🇫🇷 / 🇬🇧 contrast boxes` → `Exercises` (retrieval, escalating, exam-format last) → `Answer key` → `Write` → `Cards` (added to the queue) → `Nicos Weg link` → `Live drill prompt`.
